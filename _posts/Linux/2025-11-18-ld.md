# 1. ELF 文件的 `.dynamic` 段（动态链接信息）

| 标签         | 含义                                       |
| ------------ | ------------------------------------------ |
| `DT_INTERP`  | ELF 是可执行文件时，用于指定动态链接器     |
| `DT_SONAME`  | ELF 是动态库文件时，用于标记其"共享对象名" |
| `DT_NEEDED`  | 表示一个依赖的共享库名称，例如 libm.so.6   |
| `DT_RPATH`   | 指定运行时查找库的路径（不推荐使用）       |
| `DT_RUNPATH` | 指定运行时查找库的路径                     |

# 2. 可执行文件执行时序与动态库加载顺序

1. 加载可执行文件
2. 加载 `DT_INTERP` 指定的动态连接器
3. 加载当前 ELF 文件 `DT_NEEDED` 指定的依赖
   1. 如果只有库名，则按照以下搜索顺序动态库（按照其中的 `DT_SONAME` 确定名称）
      1. `DT_RPATH` 指定的路径（如果没有配置 `DT_RUNPATH`）
      2. 环境变量 `LD_LIBRARY_PATH`
      3. `DT_RUNPATH` 指定的路径
      4. 缓存 `/etc/ld.so.cache`
      5. 标准系统库路径 `/lib`, `/usr/lib`
   2. 如果是绝对路径，则去路径位置加载

注意
1. 对于递归的依赖，只有它们自身的 `DT_RUNPATH` 或 `DT_RPATH` 生效，不使用调用者的 `DT_RUNPATH` 或 `DT_RPATH`
2. `DT_RUNPATH` 和 `DT_RPATH` 只有一个会生效，同时包含时 `DT_RUNPATH` 有效
2. `DT_RUNPATH` 和 `DT_RPATH` 中可以使用 `$ORIGIN` 代表 ELF 文件所在目录

# 3. 检查和修改二进制的配置
## 3.1. 检查配置

```
readelf -d elf
```

输出示例：
```
 0x0000000000000015 (INTERP)             0x400234
 0x000000000000000e (SONAME)             Library soname: [libfoo.so.1]
 0x0000000000000001 (NEEDED)             Shared library: [libm.so.6]
 0x000000000000000f (RPATH)              Library rpath: [/old/path]
 0x000000000000001d (RUNPATH)            Library runpath: [/custom/path]
```

## 3.2. 修改配置

```shell
patchelf --set-interpreter INTERPRETER ELF_FILE     # 修改 DT_INTERP
patchelf --set-soname SONAME ELF_FILE               # 修改 DT_SONAME
patchelf --replace-needed LIB_ORIG LIB_NEW ELF_FILE # 修改 DT_NEEDED
patchelf --force-rpath --set-rpath RUNPATH ELF_FILE # 修改 DT_RPATH
patchelf --set-rpath RUNPATH ELF_FILE               # 修改 DT_RUNPATH
patchelf --remove-rpath ELF_FILE                    # 移除 DT_RPATH 和 DT_RUNPATH
```
